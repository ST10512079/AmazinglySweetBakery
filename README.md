Amazingly Sweet Bakery Website 

Project Overview

Amazingly Sweet Bakery is a hypothetical small business, family-owned bakery, based in Durban, KwaZulu-Natal, South Africa. The purpose of this website is to provide customer with information about the bakery, its products, menu, services, and contact details. The website also provides an enquiry page where customers can enter their details and make enquiries about products or custom orders.

Oraganisation

Business Name: Amazingly Sweet Bakery
Business Type: Small Local Bakery
Location: Durban, KwaZulu-Natal, South Africa 
Established: 2024

Purpose of the Website

- Introduces customers to Amazingly Sweet Bakery.
- Display the bakery's products and prices.
- Provide information about the bakery.
- Allow customers to make enquires.
- Provide contact information.
- Promotes customization of cakes and other baked goodes.
- Make information about the bakery easy to access.

Target Audience

The website is designed for:

- Local customers.
- Families.
- People looking for cakes and baked products.
- Customers planning birthdays and celebrations.
- Customers interested in customised cakes.
- People looking for a local bakery in Durban.

Technologies Used

This project currently uses:

HTML for the basic structure of the website.
CSS for the design of the website.
JavaScript for the functionality of the website.

Website Structure:

The website consists of 5 HTML pages:

1. Home page - "index.html"

The Home page introduces the user to the Amazingly Sweet Bakery

It contains:

- Bakery introduction.
- Featured products.
- Links to the menu and other pages

2. Menu page - "product.html"

The Menu Page provides information about the bakery's products.

It contains:

- Product list.
- Categories.
- Portion Sizes and Prices.
- Pastry Details.
- Custom order.

Products include:

- White Bread
- Whole Wheat Bread
- Multigrain Bread 
- Sourdough Bread
- Vanilla Sponge Cake/Cupcakes
- Chocolate Cake/Cupcakes
- Red Velvet Cake/Cupcakes
- Marble Cake/Cupcakes
- Tarts
- Cinnamon Rolls
- Croissants
- Cheesecakes

3. Enquires and Customer Support - "enquiry.html"

The Enquiry Page allows customers to enter information about
their enquiry.

It contains:

- Full name.
- Email address.
- Enquiry message.
- Submit button.
- Frequently Asked Questions (FAQs).
- Shipping and collection.
- Customer support.
- Customisation of orders.

4. About Us Page - "about.html"

The About Us page provides information about the bakery.

It contains:

- About the bakery.
- Bakery history.
- Company values.
- Mission.
- Vision.

5. Contact Us page - "contact.html"

The Contact Page provides ways for customers to contact the bakery.

It contains:

- Email address.
- WhatsApp contact.
- Facebook information.
- Instagram information.
- Location.
- Opening hours.
